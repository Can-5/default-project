# OpenCode Booster

OpenCode ortamını optimize eden ve güçlendiren bir skill'dir.

## Özellikler
- Ortam durumu raporu (`--status`)
- Optimizasyon önerileri (`--optimize`)
- `__pycache__` temizliği (`--clean`)

## Kullanım
```bash
python3 open_code_booster.py --status
python3 open_code_booster.py --optimize
python3 open_code_booster.py --clean
```

## Dosyalar
- `open_code_booster.py` — Ana skill dosyası
- `SKILL.md` — Skill belgeleri
